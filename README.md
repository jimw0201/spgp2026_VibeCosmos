## 게임에 대한 간단한 소개
### **High Concept**
> **"광활한 우주의 선율을 타고 적을 격파하는 2D 횡스크롤 리듬 액션"**

### **핵심 메카닉**
* **듀얼 레인 타격**: 음악의 비트에 맞춰 상/하단 레인으로 다가오는 적을 터치하여 파괴
* **싱크로 시스템**: 곡의 고유 속도(`noteSpeed`)를 기반으로 스폰 지점부터 판정선까지 도달하는 시간인 `travelTime`을 역산하여, 음악 재생 시간과 노트 생성 타이밍을 밀리초 단위로 일치시켜 동기화
* **역동적 등장**: 'Bezier Curve' 로직을 적용하여 적 기체가 곡선을 그리며 화면에 진입

## 개발 기술 명세

### **1. 사용된 기술 (Technologies Used)**
* **개발 언어 및 환경**: Kotlin, Android Studio 기반 배포 패키징 빌드 환경 구축
* **그래픽 및 화면 제어**: Android Canvas 2D Bitmap Matrix, `SurfaceView` 코어 루프 가속을 통한 고주사율 그래픽 렌더링 적용
* **비동기 처리**: Java Thread 구조를 활용한 타이틀 캐릭터 GIF 이미지의 비동기 런타임 디코딩 및 애니메이션 프레임 포스트 연산 처리
* **오디오 시스템**: `MediaPlayer` API 기반 배경 오디오 스트림 루핑 제어 및 오디오 레이턴시 최소화를 위한 `SoundPool` 멀티 채널링 스트림 제어 기술 결합

### **2. 참고한 것들 (References)**
* **인터페이스 디자인**: 2레인 기반 캐주얼 리듬 액션 게임인 *Muse Dash*의 상/하단 타격 포지션 및 링 레이아웃 조작 인터랙션 벤치마킹

### **3. 수업 내용에서 차용한 것 (Coursework Adaptation)**
* **`a2dg` 커스텀 게임 엔진 프레임워크 전면 응용**
  * `BaseGameActivity`, `Scene`, `World` 컴포넌트의 추상 구조를 상속받아 전체 게임의 씬 매니지먼트 라이프사이클 파이프라인 연결 및 구동
* **3중 패럴렉스 레이어 및 스크롤 기법**
  * `HorzScrollBackground` 속성을 커스텀 확장하여, 레이어별 독립적인 속도(Speed) 인자 대입을 통해 다층 구조로 무한 롤링하는 **3중 패럴렉스 우주 성운 스크롤 기술** 적용
* **스프라이트 애니메이션 구조**
  * 프레임워크의 `AnimSprite` 클래스를 상속 확장하여 스프라이트 시트 기반 런타임 행/열(`row/col`) 인덱스 연산 및 델타 타임(`gctx.frameTime`) 연동 플레이어 애니메이션 구현
* **JSON 기반 곡 정보 및 에셋 관리**
  * `AssetManager`를 통해 외부 `songs.json` 데이터 스트림을 로드 및 파싱하여 곡 제목, 오디오 파일, 채보 파일, 고유 속도 설정을 유기적으로 결합하는 **곡 카탈로그 로더** 구축
* **메모리 방어형 객체 재사용 구조**
  * 수업 중 다룬 가비지 컬렉터 관리 기법을 차용하여 화면 밖으로 나간 노트를 즉시 파괴하지 않고 `world.obtain()` 및 `IRecyclable` 인터페이스로 회수하여 인스턴스를 재활용하는 **오브젝트 풀링(Object Pooling) 구조** 적용

### **4. 직접 개발한 것 (Original Development)**
* **밀리초(ms) 단위 고정밀 오디오 역산 싱크 매니저 (`NoteManager`)**
  * 외부 에셋의 `timeMs | lane | lengthMs` 텍스트 차트 데이터를 파싱해 FIFO 구조의 데이터 큐(`Queue`)에 적재하는 채보 파서 자체 구현
  * 곡의 고유 속도(`noteSpeed`)에 따라 노트가 화면 끝에서 판정선까지 도달하는 스폰 소요 시간(`travelTime`)을 밀리초 단위로 역산, 하드웨어 주사율 렉에 영향받지 않고 오디오 타임스탬프와 완벽히 맞물려 스폰되는 **독창적인 물리 기반 싱크 엔진** 구축
* **2차 베지에 곡선(Bézier Curve) 적 기체 진입 알고리즘**
  * 일반 단타 노트 스폰 시 화면 외곽 제어점(P0, P1, P2) 사이의 프레임 타임 변화량을 2차 베지에 공식으로 보간 연산하여 동적으로 곡선을 그리며 다가오는 적 기체 이동 궤적 알고리즘 설계 및 구현
* **3단 조립형 가변 롱노트 서스테인 시스템**
  * 롱노트 데이터 파싱 시 헤드(Head), 라인(Line), 테일(Tail) 비트맵을 분리한 뒤, 연산된 `noteLengthPx`만큼 실시간으로 신축성 있게 늘려 그리는 조립식 렌더링 모듈 직접 설계
  * 홀드 지속 중 $0.1$초 간격으로 누적 점수를 계산하는 `holdTickAccumulator` 로직과, 끝부분에서 손을 떼는 릴리즈 순간 단타용 공격 사운드가 중복 출력되거나 판정이 누락되지 않도록 동적 분기하는 예외 처리 엔진 구현
* **실시간 곡 진행도 연산 및 동적 가로폭 드로우 가이드 (HUD)**
  * 인게임 화면 상단에 `MediaPlayer`의 실시간 재생률(`currentPosition / duration`)을 프레임 단위로 수집 및 가공하는 연산 모듈 탑재
  * 기존 점수판 UI와 겹치지 않도록 우측 상단 영역에 실시간으로 차오르는 상태 게이지바 구현

## 수업 소감 및 피드백

### **1. 이번 수업에서 기대한 것, 얻은 것, 얻지 못한 것**
* **기대한 것**
  * 모바일 표준 개발 환경인 안드로이드 스튜디오와 코틀린 언어의 기초 활용 능력 습득
* **얻은 것**
  * 이번 수업을 통해 안드로이드 스튜디오와 코틀린이라는 언어를 완전히 처음 접했음에도 불구하고, 수업 중 배운 내용들을 토대로 간단한 게임을 완성할 수 있을 수준의 활용 능력
* **얻지 못한 것**
  * 한 학기라는 제한된 시간적 제약으로 인해, 안드로이드 스튜디오와 코틀린 언어에 대해 깊게 파고들지 못한 것

### **2. 더 좋은 수업이 되기 위해 변화할 점**
 * 초반엔 직접 프로젝트를 만들어서 따라하며 실습을 통해 이해를 하였지만, 후반에는 다루는 콘텐츠의 양이 방대해지고 로직이 복잡해져 실시간 라이브 코딩보다는 교수님의 화면과 커밋 내역을 추적하는 데 집중해야 하여 이해가 힘들어졌다.
